Overview — How to use this roadmap

Estimated: 6–12+ months

This roadmap is organized into progressive phases. Complete the practical mini-projects in each phase before moving to the next. You can speed up or slow down depending on time availability — the content is modular.

  • Do the projects: Theory is important but practical builds intuition. Each phase contains 2–5 projects — complete them.
  • Keep a portfolio: Push code to GitHub and write short READMEs for each project.
  • Iterate: Revisit earlier phases after learning later concepts — e.g. rewrite a pandas pipeline using what you learned in DL.

Phase 1 — Programming Foundation (Python)

2–4 weeks

Why Python? It's the industry standard for ML/DL with rich libraries and community support.

Core Topics

  • Python basics: variables, types, control flow (if/for/while)
  • Data structures: lists, tuples, dicts, sets
  • Functions, modules, packages, virtual environments (venv / pip)
  • Object-oriented programming: classes, inheritance
  • File IO, JSON handling, exception handling

Practical Setup

  • Install Python 3.10+ and set up venv.
  • Preferred editor: VS Code — install Python extension and Git integration.
  • Use Git from day 1. Initialize a repo: 
    git init
git add .
git commit -m "initial"

Mini Projects (do them)

  • Calculator CLI
  • Tic-Tac-Toe with a simple AI
  • Password generator and a small CLI menu app

Phase 2 — Math for ML

4 weeks

You don't need advanced math — just the parts you will use often in ML and DL.

Click here for the Detailed Teacher-Student Style Guide

Linear Algebra

  • Vectors and matrices, matrix multiplication, dot product
  • Eigenvalues & eigenvectors (basic intuition)

Calculus & Optimization

  • Derivatives and gradients
  • Gradient descent, learning rate, convexity intuition

Probability & Statistics

  • Mean, variance, standard deviation
  • Probability distributions (normal, bernoulli, binomial)
  • Bayes' theorem, likelihood

Small Exercises

  • Implement matrix multiplication with nested loops and then with numpy.
  • Write gradient descent to fit a linear regression model from scratch.

Phase 3 — Data Handling (Pandas & NumPy)

2 weeks

Most real-world work is data cleaning and preprocessing. Be excellent at this.

Click here for the Detailed Data Handling Guide

Skills

  • CSV / JSON reading & writing (pandas.read_csv)
  • Handling missing values, duplicates, and outliers

Mini Projects

Phase 4 — Machine Learning Core

6–8 weeks

Start building and comparing classical ML models. Understand when to use each model.

Click here for the Detailed Machine Learning Guide

Important Algorithms

  • Linear & Logistic Regression
  • Decision Trees, Random Forests
  • K-Nearest Neighbors, SVMs
  • Gradient Boosting & XGBoost
  • K-Means, PCA (unsupervised)

Model Evaluation

  • Train/test split, cross validation
  • Precision, recall, F1, ROC-AUC
  • Bias vs variance, regularization (L1/L2)

Tools

  • scikit-learn — practice the API: 
    from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
clf = RandomForestClassifier(n_estimators=100)
clf.fit(X_train, y_train)
print(clf.score(X_test, y_test))

Mini Projects

  • House price prediction (regression)
  • Spam detection (text -> bag of words -> model)
  • Customer churn prediction
  • Recommender system (collaborative filtering baseline)

Phase 5 — Deep Learning (PyTorch recommended)

8–12 weeks

Deep learning unlocks computer vision, speech, and modern NLP workflows. PyTorch is recommended for clarity and industry demand.

Click here for the Detailed Deep Learning Guide

Core concepts

  • Tensors, autograd, computational graph
  • Neural network layers, activation functions
  • Loss functions, optimizers (SGD, Adam)

Architectures

  • Feed-forward networks (MLP)
  • Convolutional Neural Networks (CNNs) for images
  • RNN / LSTM / GRU for sequences
  • Autoencoders & basic GANs (generative models)

Minimal PyTorch example

import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self, input_size, hidden, out):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_size, hidden),
            nn.ReLU(),
            nn.Linear(hidden, out)
        )
    def forward(self, x):
        return self.net(x)

model = SimpleNet(784, 128, 10)
print(model)

Mini Projects

  • MNIST digit classifier from scratch
  • Image classification on CIFAR-10
  • Text sentiment classification using embedding + LSTM
  • Introduce transfer learning (ResNet, MobileNet)

Phase 6 — NLP & Large Language Models (LLMs)

6–12 weeks

NLP evolved fast — transformers and LLMs are central. Learn both foundations and practical fine-tuning.

Click here for the Detailed NLP & LLMs Guide

Foundational Topics

  • Tokenization, embeddings (Word2Vec/GloVe)
  • Attention mechanism & Transformer building blocks
  • Encoder-only (BERT), decoder-only (GPT), encoder-decoder (T5)

Practical LLM Skills

  • Fine-tuning for classification or generation
  • Prompt engineering and evaluation
  • Retrieval Augmented Generation (RAG) pipelines
  • Vector databases and embeddings (FAISS, Milvus, Pinecone)
  • Frameworks: Hugging Face Transformers, LangChain

Mini Projects

  • Build a document Q&A bot (PDF -> embeddings -> RAG)
  • Fine-tune a smaller transformer for sentiment analysis
  • PDF resume analyzer that extracts skills & scores them

Phase 9 — Portfolio & Interview Prep

Ongoing

Real proof of skill is projects — make them public, document them, and be able to explain trade-offs.

Helpful Study Schedule (example)

If you can commit ~10–15 hours/week, here's a compact plan.

  • Months 1–2: Python + Math + Data handling — finish Phase 1–3
  • Months 3–4: Core ML and 3 projects — finish Phase 4
  • Months 5–7: Deep Learning + 3 DL projects — finish Phase 5
  • Months 8–9: NLP + LLMs + RAG projects — finish Phase 6
  • Months 9–10: MLOps + deployment projects — Phase 7
