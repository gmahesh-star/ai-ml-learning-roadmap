Phase 3 — Data Handling (Pandas & NumPy)

Duration: 2 Weeks
Objective: Develop the skills required to clean, explore, transform, and understand data. This is the most practical skill in the entire AI/ML journey because every ML or DL model depends entirely on data quality.

1. Introduction: Why Data Handling Matters

In real-world AI development, nearly 70% of the work revolves around data.
A model performs only as well as the data you feed it. Even the most advanced neural network cannot compensate for poorly cleaned, badly structured or misunderstood data.

Phase 3 trains you to think like a data engineer:
To read, inspect, clean, reshape, and understand raw data.

Good data handling skills differentiate a beginner ML student from someone who can build professional-grade models.

2. Core Tools You Must Learn

During Phase 3, you mainly work with three Python libraries:

NumPy

  • Foundational numerical computing library.
  • Used for vectorized operations, arrays, and fast mathematical computation.

Pandas

  • The primary tool for structured data manipulation in Python.
  • Built on top of NumPy and used to handle datasets in rows and columns.

Matplotlib

  • The fundamental plotting library.
  • Used for simple data visualization.

If one masters these three tools, they can work with most datasets encountered in machine learning.

3. What You Should Learn in Pandas

Below are the essential topics a learner must understand thoroughly. Do not skip these; they form the backbone of data science.

3.1 Reading and Writing Data

Learn how to read and write datasets in multiple formats.

Key functions:

  • pandas.read_csv()
  • pandas.read_json()
  • pandas.read_excel()
  • DataFrame.to_csv()
  • DataFrame.to_json()
  • DataFrame.to_excel()

You must be able to load a dataset, inspect it, clean it, and write it back.

3.2 Inspecting Data

When you load a dataset, begin with:

  • df.head()
  • df.tail()
  • df.info()
  • df.describe()
  • df.columns
  • df.shape

Develop a habit of understanding:

  • What type of data each column contains.
  • Whether columns have missing values.
  • Whether values are numerical or categorical.
  • Whether the dataset has duplicates.

This is the first and most important step of data work.

3.3 Handling Missing Values

Missing data is extremely common. You will learn:

  • Identifying missing values using df.isnull().sum()
  • Filling missing values:
    • Numerical: mean, median, mode
    • Categorical: mode
    • Domain-specific strategies
  • Dropping rows or columns if necessary: df.dropna()

Do not blindly drop data; you must maintain a balance between data size and quality.

3.4 Handling Duplicates

Datasets often contain exact duplicate rows, which need to be addressed.

  • Find duplicates: df.duplicated()
  • Remove duplicates: df.drop_duplicates()

This step prevents repeated information from influencing the model.

3.5 Handling Outliers

Certain values may be extremely large or small and can distort model training.

Learn methods such as:

  • Interquartile range (IQR)
  • Box plot interpretation
  • Capping or flooring values (winsorization)
  • Domain-specific rules

Handling outliers requires logical thinking more than memorization.

3.6 Feature Engineering

Feature engineering refers to the process of transforming raw features into meaningful format for ML.

Learn techniques such as:

  • Creating new features from existing ones
  • Splitting columns (for example, extracting year/month/day from a date)
  • Binning numerical data (low, medium, high categories)
  • Normalizing text data
  • Combining multiple columns to create new metrics

Feature engineering is where human creativity matters most.

3.7 Encoding Categorical Data

Most ML models accept only numerical data.
Therefore, categorical columns must be encoded.

Learn:

  • Label encoding
  • One-Hot encoding using:
    • pd.get_dummies()
    • sklearn.preprocessing.OneHotEncoder

Know when to use which method:

  • Label encoding for ordinal categories
  • One-hot encoding for non-ordinal categories

3.8 Scaling Numerical Data

Scaling ensures that all features contribute equally to model training.

Learn:

  • Standardization (z-score scaling)
  • Min-max scaling
  • Robust scaling

Use:

  • sklearn.preprocessing.StandardScaler
  • sklearn.preprocessing.MinMaxScaler

Scaling is essential for distance-based models, neural networks, and PCA.

4. What You Should Learn in NumPy

NumPy is used under the hood even when using pandas.
Skills you must acquire:

  • Creating arrays
  • Indexing and slicing arrays
  • Vectorized operations
  • Broadcasting rules
  • Aggregation functions (mean, sum, max, min)
  • Basic reshaping (reshape, flatten, transpose)

Focus on writing operations without loops because vectorization makes code significantly faster.

5. Basic Data Visualization (Matplotlib)

Visualization is critical for understanding data. You learn how to:

  • Plot histograms to understand distribution
  • Plot scatter plots to identify relationships
  • Plot box plots to detect outliers
  • Plot bar charts for categorical comparisons

Visualizations help you detect:

  • Trends
  • Clusters
  • Outliers
  • Patterns
  • Missing patterns in the data

It is not necessary to master deep visualization libraries during Phase 3. Matplotlib basics are enough.

6. How to Study in Phase 3

Follow these principles:

  • Always explore the dataset before cleaning it.
  • Never perform transformations blindly; understand why they are needed.
  • Keep a notebook where you record patterns you observe.
  • Practice with multiple datasets instead of sticking to one.
  • Save intermediate results and compare before/after versions of data.
  • Read documentation for functions you use; it builds long-term skill.

7. What Not to Do

  • Do not attempt advanced statistics yet; keep it simple.
  • Do not try to memorize all pandas functions. Practice is enough.
  • Do not skip exploratory data analysis. It is the heart of Phase 3.
  • Do not spend time learning seaborn or plotly in this phase. Stick to matplotlib.
  • Do not assume data is clean just because it looks clean at first glance.

8. Mini Projects (Must Complete Before Phase 4)

Project 1: Movie Dataset EDA and Visualization

Steps you must perform:

  • Load the dataset
  • Inspect columns and types
  • Handle missing values
  • Clean inconsistent data
  • Analyze:
    • Ratings distribution
    • Genre frequency
    • Correlation between budget and revenue
  • Visualize:
    • Histograms
    • Scatter plot
    • Bar charts

This project teaches end-to-end EDA.

Project 2: Titanic Dataset or House Prices Dataset

Choose one.

Required tasks:

  • Read dataset
  • Analyze structure
  • Perform full cleaning:
    • Missing values
    • Outliers
    • Encoding
    • Scaling (if needed)
  • Perform basic model training:
    • Logistic Regression for Titanic
    • Linear Regression for House Prices
  • Evaluate performance
  • Document findings in a README

The goal of this project is to simulate a real-world analytics pipeline.

9. Expected Outcome of Phase 3

By the end of these 2 weeks, learners should be capable of:

  • Reading and exploring any structured dataset
  • Identifying issues such as missing values and outliers
  • Performing complete data cleaning steps
  • Encoding categorical data
  • Scaling numerical features
  • Performing basic EDA and visualization
  • Preparing data for machine learning models
  • Creating simple baseline models with cleaned data

Anyone who completes Phase 3 with focus will be ready for Phase 4: Machine Learning Core.
