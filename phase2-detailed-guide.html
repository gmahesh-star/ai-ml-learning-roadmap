Phase 2 — Math for Machine Learning (Teacher–Student Style Guide)

Duration: 4 weeks
Goal: Build the exact amount of math needed for ML & DL — nothing extra, nothing scary.

Before You Start — Read This

Phase 2 math is NOT like your school math where you memorize formulas.
Here, you learn how math builds ML models.

You are not learning math to score marks —
You're learning math to understand how AI thinks.

I'll tell you exactly what to do, what not to do, and how to practice.

Let's begin.

WEEK 1 — Linear Algebra (The Foundation of ML & DL)

1. What you must learn

Vectors
Think of a vector as a list of numbers:
[height, weight, age] — this is a vector representing a person.

Matrices
A matrix is just many vectors stacked.
Every dataset you use is essentially a matrix.

Dot Product
This is the most important operation.
In neural networks, every neuron does:

output = w1*x1 + w2*x2 + w3*x3 + ...

This is a dot product.

Matrix Multiplication
Used in every ML/DL model (Linear Regression → CNNs → Transformers).

2. How to learn it (step-by-step)

  • Watch short visual videos (3Blue1Brown — "Essence of Linear Algebra").
  • Take a notebook. Re-draw what you understood.
  • Implement vector addition, dot product, and matrix multiplication manually on paper.
  • THEN try with Python + NumPy (to see how easy computers do it).

3. What NOT to do

  • Don't try to learn determinants, advanced theorems, proofs.
  • Don't aim for perfection — intuition is enough.
  • Don't spend more than 1 week here.

Practice Exercises

  • Multiply two 2×2 matrices on paper.
  • Compute dot product of two 3-dim vectors.
  • Using Python, recreate matrix multiplication using 3 nested loops.
  • Then redo it using NumPy: A @ B.

WEEK 2 — Calculus & Optimization (How Models Learn)

1. Derivatives & Gradients

In ML, a derivative tells you how fast the error changes.

  • If error increases → bad direction
  • If error decreases → good direction

This is how a model learns weights.

2. Gradient Descent

This is the heart of machine learning.

Imagine you are blindfolded on a hill. You want to reach the lowest point.
What do you do?
Feel the slope
Take small steps downward
Keep going until you reach the minimum

That's gradient descent.

Key terms:

  • Learning rate: How big the step is
  • Loss function: What the model is trying to minimize
  • Convergence: Reaching the lowest loss

How to learn it

  • Watch a video: "Gradient Descent — 3Blue1Brown".
  • Draw graphs in notebook showing slopes.
  • Understand how slope gives you direction.
  • Try to compute derivative of a simple function:
    • f(x) = x²
    • f(x) = x³ + 2x
  • Only basics. No advanced calculus needed.

What NOT to do

  • Don't study integration, limits, proofs.
  • Don't do 20 derivative problems — 3–4 is enough.
  • Don't aim to derive formulas used in ML. We only need intuition.

Practice Exercises

  • Take the function f(x)=x²; write the derivative.
  • Pick a random point like x=4 — check slope.
  • Simulate gradient descent on paper:
    • x = 4
    • learning rate = 0.1
    • update rule: x = x − learning_rate * derivative
    • Do 3 steps.

WEEK 3 — Probability & Statistics (Understanding Data)

Mean, Variance, Standard Deviation

Understand what these tell you:

  • Mean: average
  • Variance: how spread data is
  • Standard Deviation: how far values are from mean

ML algorithms like Naïve Bayes, PCA depend heavily on these.

Probability Distributions

Learn these 3 only:

  • Normal (Gaussian): bell-curve
  • Bernoulli: yes/no
  • Binomial: repeated yes/no events

Bayes' Theorem

Used in:

  • Naive Bayes
  • Spam filtering
  • Probabilistic models

You only need conceptual understanding.

Likelihood

This measures how probable the data is for a given parameter.
Used in:

  • Logistic regression training
  • Maximum likelihood estimation (MLE)

How to Study

  • Watch videos from Khan Academy.
  • Take a small dataset and compute mean, variance manually.
  • Visualize distributions using Matplotlib.

What NOT to do

  • Don't study permutation, combination unless needed.
  • Don't learn advanced statistics like t-tests, chi-square, etc.
  • Don't memorize formulas. Understand intuitions.

WEEK 4 — Practical Math Projects

This is the most important part.
Math becomes useful only when you apply it.

Project 1: Matrix Multiplication

  • Implement with 3 loops
  • Implement with NumPy
  • Measure time difference

You'll understand how optimized NumPy is.

Project 2: Gradient Descent Regression

You will:

  • Take y=2x+3 + noise
  • Start with random slope & intercept
  • Use gradient descent to adjust them
  • Make your model learn the correct values

This teaches:

  • Loss function
  • Gradients
  • Convergence

Project 3: Distribution Visualization

Take random data and plot:

  • Histogram
  • PDF
  • CDF

You will visually understand probability for the first time.

What You Should Focus On

DO THIS

  • Gain intuition
  • Draw graphs
  • Implement small exercises
  • Ask "why does this matter in ML?"
  • Do the mini-projects
  • Spend 30–45 minutes daily

DO NOT DO THIS

  • Don't open advanced math books
  • Don't try to become a mathematician
  • Don't spend weeks stuck on small formulas
  • Don't try to memorize equations

Final Goal of Phase 2

By the end of these 4 weeks, you should be able to:

  • Explain vectors, matrices, and dot products
  • Compute gradients intuitively
  • Understand how gradient descent optimizes a model
  • Describe normal, bernoulli, and binomial distributions
  • Compute mean & variance of any dataset
  • Write basic mathematical operations in Python
  • Understand ML algorithms deeply when you reach Phase 4

If you achieve these, your ML foundation will be stronger than 90% of beginners.
