Phase 4 — Machine Learning Core

Duration: 6–8 Weeks
Objective: Develop strong theoretical understanding and practical proficiency in classical Machine Learning. This phase will give you the ability to build, train, evaluate, and compare ML models that solve real problems.

1. Introduction: Why Phase 4 Matters

Machine Learning is the foundation of AI. Even though deep learning and LLMs dominate today's world, classical ML algorithms remain essential because:

  • They are fast to train.
  • They work well with small to medium-sized datasets.
  • They are easier to interpret and debug.
  • They remain the starting point in most industry workflows.

A person who truly understands classical ML can understand deep learning more easily, because the principles of optimization, generalization, and model evaluation remain similar.

Phase 4 is where you bridge data handling skills (Phase 3) with modeling and prediction.

2. The Workflow of Machine Learning

Before studying individual algorithms, learners must understand the ML workflow:

  • Define the problem
  • Collect and clean data
  • Prepare features
  • Split data into train and test sets
  • Select algorithms
  • Train models
  • Evaluate performance
  • Tune hyperparameters
  • Compare models
  • Deploy or finalize model

Every ML project in industry follows this pipeline.

3. Supervised Learning Algorithms (Essential Set)

This section covers algorithms used for regression (predicting continuous numbers) and classification (predicting categories).

3.1 Linear Regression

Purpose: Predict continuous values (e.g., house prices).

Concepts to understand:

  • Linear relationship between features and target
  • Cost function (Mean Squared Error)
  • Gradient Descent vs Closed Form Solution
  • Overfitting and underfitting
  • Regularization (L1/Lasso, L2/Ridge)

Practical tasks:

  • Fit a regression line
  • Plot residuals
  • Interpret model coefficients
  • Evaluate using MAE, MSE, RMSE, R²

Linear regression teaches core mathematical foundations used in deep learning.

3.2 Logistic Regression

Purpose: Classification tasks (yes/no outcomes).

Important concepts:

  • Sigmoid function
  • Decision boundary
  • Probability outputs
  • Binary cross-entropy loss
  • Multiclass classification (One-vs-Rest)

This is the most important classification model for beginners. It is interpretable, fast, and widely used.

3.3 Decision Trees

Purpose: Both regression and classification.

Advantages:

  • Easy to understand
  • Handles nonlinear patterns
  • Handles categorical and numerical data

Concepts to learn:

  • Gini impurity
  • Entropy
  • Information gain
  • Tree depth
  • Overfitting in trees
  • Pruning techniques

Decision trees form the base of advanced algorithms like Random Forests and XGBoost.

3.4 Random Forest

An ensemble of decision trees.

Strengths:

  • High accuracy
  • Less prone to overfitting
  • Works on most datasets

Concepts:

  • Bagging (bootstrap aggregating)
  • Majority voting / averaging
  • Feature importance

Random Forests are often the first baseline model used in industry.

3.5 K-Nearest Neighbors (KNN)

A simple but effective model.

Concepts to learn:

  • Distance metrics (Euclidean, Manhattan)
  • Choosing K
  • Curse of dimensionality
  • Scaling necessity

It is slow for large datasets but excellent for conceptual understanding.

3.6 Support Vector Machines (SVM)

A powerful algorithm for both regression and classification.

Concepts:

  • Hyperplanes
  • Margins
  • Support vectors
  • Kernel trick (RBF, polynomial, linear)
  • Soft margin vs hard margin

SVMs perform exceptionally well on high-dimensional data.

3.7 Gradient Boosting and XGBoost

These are among the most powerful classical ML techniques.

Key concepts:

  • Boosting (sequential learning)
  • Weak learners
  • Loss reduction at each stage

Hyperparameters:

  • learning rate
  • max depth
  • number of estimators

XGBoost, LightGBM, and CatBoost are widely used in Kaggle competitions and industry projects.

4. Unsupervised Learning Algorithms

These algorithms discover patterns and structure in data without labeled outputs.

4.1 K-Means Clustering

Used for grouping similar data points.

Concepts:

  • Centroids
  • Distance from center
  • Inertia
  • Elbow method
  • Limitations (spherical clusters, sensitivity to outliers)

4.2 Principal Component Analysis (PCA)

Used for dimensionality reduction.

Concepts:

  • Variance
  • Covariance matrix
  • Eigenvectors
  • Projection into lower dimensions
  • Importance of scaling before PCA

PCA is critical in preprocessing high-dimensional data.

5. Data Splitting and Cross-Validation

Every ML model must be evaluated properly.

Key steps:

  • Train-test split
  • Validation set
  • K-Fold cross-validation
  • Stratified splitting (for imbalanced data)

Cross-validation prevents unreliable results and overfitting.

6. Model Evaluation

The correct metrics must be used for each type of problem.

6.1 Classification Metrics

  • Accuracy
  • Precision
  • Recall
  • F1 score
  • Confusion matrix
  • ROC curve
  • AUC score

Learners must understand the tradeoff between precision and recall.

6.2 Regression Metrics

  • MAE
  • MSE
  • RMSE
  • R² score

Different datasets require different metrics.

7. Hyperparameter Tuning

Models have parameters and hyperparameters.
Hyperparameter tuning significantly improves performance.

Methods:

  • Grid Search
  • Random Search
  • Bayesian optimization (advanced)

Hyperparameter tuning should be applied after building a baseline model.

8. Practical Exercises and Mini Projects

These projects must be completed to gain practical mastery.

Project 1: House Price Prediction (Regression)

Tasks:

  • Load dataset
  • Perform full cleaning
  • Select features
  • Train Linear Regression
  • Train Random Forest Regression
  • Compare metrics
  • Visualize predictions vs actual data

Objective: Understand regression deeply.

Project 2: Spam Detection (Classification)

Tasks:

  • Clean text
  • Convert text to numerical features (bag-of-words or TF-IDF)
  • Train Logistic Regression and Naive Bayes
  • Evaluate using precision and recall
  • Visualize confusion matrix

Objective: Learn classification and text preprocessing.

Project 3: Customer Churn Prediction

Tasks:

  • Handle categorical and numerical data
  • Encode features
  • Train multiple models (Logistic Regression, Random Forest, XGBoost)
  • Tune hyperparameters
  • Rank models by performance

Objective: Learn end-to-end ML pipeline.

Project 4: Recommendation System (Basic)

Tasks:

  • Create user-item matrix
  • Implement collaborative filtering or simple similarity-based recommendations
  • Evaluate results

Objective: Understand unsupervised-like modeling with similarity.

9. What Learners Should Avoid

  • Do not memorize algorithms; understand their intuition.
  • Do not skip evaluation metrics; they are essential.
  • Do not start with deep learning before mastering classical ML.
  • Do not blindly trust accuracy; always inspect precision and recall.
  • Do not tune hyperparameters before building a baseline model.

10. Expected Outcome of Phase 4

By the end of this phase, learners should be able to:

  • Identify whether a ML problem is classification or regression
  • Understand and implement major ML algorithms
  • Perform complete model training and evaluation
  • Compare models and select the best one
  • Tune hyperparameters effectively
  • Build end-to-end ML pipelines
  • Read ML research or documentation with clarity
  • Prepare for Deep Learning (Phase 5) with confidence

Phase 4 turns a beginner into a capable machine learning practitioner ready for advanced study.
